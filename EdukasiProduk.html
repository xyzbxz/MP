Perangkat Tidak Ditemukan

Komputer

Komputer Portabel (Laptop)

Sistem komputer ringkas terintegrasi baterai untuk mendukung produktivitas kerja fleksibel di mana saja.

Komputer

Komputer Desktop (PC Tower)

Sistem komputasi stasioner berdaya konstan untuk beban kerja terpusat di meja kantor atau laboratorium.

Komputer

Central Processing Unit (CPU)

Unit logika pusat tumpuan eksekusi baris kode instruksi software dan aritmatika biner data.

Komputer

Dedicated Graphics Card (GPU)

Akselerator perangkat keras khusus pemrosesan visual paralel besar, render 3D, dan komputasi AI.

Komponen

Penyimpanan Kilat (SSD NVMe)

Media penyimpanan berbasis sirkuit digital super cepat untuk mendongkrak performa akselerasi sistem.

Komponen

Hard Disk Drive (HDD Internal)

Media penyimpanan magnetik berkapasitas besar dengan harga ekonomis untuk penimbunan file arsip.

Komponen

Memori Acak Sistem (RAM)

Komponen penampung data instruksi aplikasi sementara untuk menjamin kelancaran aktivitas multitasking.

Komponen

Papan Induk Sistem (Motherboard)

Papan sirkuit cetak utama jalur interkoneksi bus data elektromekanis antar-komponen hardware.

Komponen

Power Supply Unit (PSU)

Unit konverter energi listrik AC tegangan tinggi dinding menjadi arus searah DC low-voltage yang stabil.

Jaringan

Router Nirkabel Dual-Band

Infrastruktur pembagi paket data internet dan pemancar sinyal Wi-Fi di area gedung atau ruangan.

Jaringan

Switch Hub Manageable L2/L3

Perangkat distribusi lalu lintas data lokal terkonfigurasi berbasis MAC Address untuk segmentasi jaringan.

Keamanan & Daya

Uninterruptible Power Supply (UPS)

Sistem penyimpan energi darurat dan filter penstabil gelombang listrik untuk proteksi hardware.

Jaringan & Perangkat

Monitor Display (Panel IPS)

Layar monitor eksternal penunjang visualisasi kerja dengan kenyamanan sudut pandang mata maksimal.

Perangkat

Keyboard Kerja Mekanikal

Alat input data karakter fisik dengan arsitektur saklar independen untuk efisiensi ketik jangka panjang.

Keamanan

Kamera Pengawas (IP CCTV)

Sistem perekaman visual digital real-time untuk audit pengawasan keamanan lingkungan aset perusahaan.
